05 — Architecture
What's Inside
01

Reverse-Mode Autograd

Full DAG with 20+ differentiable ops. LogSoftmax, thread-safe graph, no_grad mode, DOT and Mermaid export.

02

BLAS + Metal GPU

394 GFLOPS via Apple Accelerate. Metal compute shaders for large matmuls. Rayon parallelism for element-wise ops.

03

nn::Module

Composable modules. Dense, ReLU, LogSoftmax, Sequential container. Persistent optimizer state with rebind.

04

Optimizers

AdamW, Adam, SGD with momentum, RMSProp, AdaGrad. Gradient clipping. Persistent first and second moment state.

05

Loss Functions

NLL, MSE, BCE, cross-entropy, Huber, hinge, KL-divergence, cosine. All differentiable through the autograd graph.

06

Neural Layers

Linear, Conv1D/2D, RNN, GRU, LSTM, multi-head attention, transformer blocks, embedding, dropout, batch norm.

07

Classical ML

Ridge, lasso, elastic net, SVM, KNN, decision trees, random forest, naive Bayes, DBSCAN, k-means, t-SNE.

08

NLP Pipeline

Word2Vec from scratch. Character-level language model. Vocabulary building, unigram noise distribution, analogy tests.

09

Serialization

Model save and load. Checkpoint system. Computation graph visualization to DOT and Mermaid formats.

use oxidize_ml_core::Tensor;
use oxidize_ml_autodiff::{Variable, backward, reset_graph};
use oxidize_ml_loss::nll_loss;
use oxidize_ml_optim::{AdamW, Optimizer};

// Build model
let model = ModuleSequential::new()
    .add(DenseModule::new(784, 256))
    .add(ReLUModule)
    .add(DenseModule::new(256, 10))
    .add(LogSoftmaxModule);

let mut opt = AdamW::new(model.collect_tensors(), 0.001);

for epoch in 0..100 {
    reset_graph();
    let pvars = model.make_param_vars();
    let out   = model.forward_with(&x, &pvars);
    let loss  = nll_loss(&out, &target);
    let grads = backward(&loss);
    opt.rebind(pvars.iter().map(|v| v.node_id).collect());
    model.load_tensors(&opt.step(&grads));
}
